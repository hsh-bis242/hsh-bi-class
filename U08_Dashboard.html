Power BI Setup

Installation & Datenanbindung

Installation von Power BI

Power BI Desktop ist auf den Labor-PCs bereits vorinstalliert. Für private Computer:

→ Power BI Desktop im Microsoft Store

Tipp: Beim ersten Start verlangt Power BI eine Anmeldung. Diese kann einfach weggeklickt werden – Power BI funktioniert trotzdem.

Verbindung zu Databricks

Aufgabe

Stellen Sie eine Verbindung zu Ihrem Star-Schema her. Wählen Sie Databricks als Datenquelle aus.

Server-Hostname: dbc-15d76289-5b7c.cloud.databricks.com
HTTP-Pfad: /sql/1.0/warehouses/4c4bcb9dfa01a5f0
Tipp: Die Connection-Details finden Sie auch direkt in Ihrem Databricks Workspace unter SQL Warehouses → Connection Details.

Tabellen auswählen

Aufgabe

Wählen Sie alle Tabellen und Views im Schema willibald_ol_dm der Datenbank bis242_XX aus und klicken Sie auf „Laden".

Datenmodell

Beziehungen & Hierarchien

Beziehungen aufbauen

Power BI erkennt Fremdschlüsselbeziehungen anhand gleichlautender Spaltennamen automatisch.

Aufgabe

Wechseln Sie in die Modellansicht und prüfen Sie das entstandene Datenmodell.

Modell bereinigen

Aufgabe

  • Verbergen Sie die HKEY-Spalten in allen Tabellen
  • Passen Sie die Tabellennamen an (Datenbank-/Schemanamen entfernen)

Hierarchien anlegen

Aufgabe

Legen Sie folgende Hierarchien an:

  • Adress-Hierarchie (in beiden Adress-Dimensionen):
    country → city → postal_code
  • Produktkategorien-Hierarchie:
    supercategory_name → productcategory_name

Die in Hierarchien verwendeten Datenfelder können Sie anschließend ausblenden.

Dashboard

KPIs visualisieren

Dashboard entwerfen

Aufgabe

Entwerfen und implementieren Sie ein Dashboard, das folgende KPIs übersichtlich darstellt:

  • Wie verteilen sich die Umsätze auf die Produktkategorien?
  • Welches sind die umsatzstärksten Städte (nach Lieferort)?
  • Wie häufig werden Samen verspätet geliefert?
  • Was ist die durchschnittliche Lieferzeitabweichung pro Lieferdienst?
  • Welches sind die 5 umsatzstärksten und die 5 umsatzschwächsten Produkte?

Umsetzungshinweise

Snapshotdatum filtern

Für korrekte Ergebnisse muss die Auswertung auf genau ein Snapshotdatum gefiltert sein.

Erstellen Sie zuerst einen Filter für die aktuelle oder alle Seiten auf ein Snapshotdatum Ihrer Wahl.
