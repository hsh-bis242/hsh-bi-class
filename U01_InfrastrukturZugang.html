Einrichten der Übungsumgebung

Die Einrichtung der Übungsumgebung erfolgt mithilfe folgender Technologien:

  1. Terraform als Infrastructure-as-Code-Softwaretool (IaC) zum Bereitstellen der verschiedenen Azure Services:
    • Resourcengruppe
    • Storage Account
    • Storage Container
    • Microsoft SQL-Server
  2. .BacPac-Datei mit Modell und Daten des Core-DWH
  3. Powershell-Skript, zum Initialisieren des Core-DWH

Download der Dateien

Vor Inbetriebnahme der Infrastruktur, laden Sie bitte folgende drei Dateien herunter:

  • main.ps1
  • main.tf
  • Willibald.bacpac

Installation in Azure

Zur Einrichtung der Übungsumgebung in Azure nutzen wir Terraform als Infrastructure-as-Code-Softwaretool (IaC).

  1. Bitte laden Sie beide Dateien (main.ps1 und main.tf) über die Azure CLI hoch.
  2. Ihr Benutzer darf keine neue Ressourcengruppe erstellen.
  3. Auch haben Sie beim Start der Cloud Shell bereits einen Storage Account erstellt.
  4. Anschließend stellen Sie bitte die Infrastruktur mit folgenden Commands bereit:
						
							terraform init
							terraform import -var "groupnumber=XX" azurerm_resource_group.rgBI /subscriptions/1f75bacb-8d7d-4e96-87cb-f7e4216886e5/resourceGroups/rgBI
							terraform import -var "groupnumber=XX" azurerm_storage_account.bistorage /subscriptions/1f75bacb-8d7d-4e96-87cb-f7e4216886e5/resourceGroups/rgBI/providers/Microsoft.Storage/storageAccounts/biXX
							terraform apply -var "groupnumber=XX" -var "sqlpassword=ryDZo5*~71[Q-"

Die Ausführung kann bis zu 15 Minuten dauern. Anschließend steht die Infrastruktur bereit.

Import des Core-DWH (1/2)

Nun muss noch das Core-DWH importiert werden. Dazu sind folgende Schritte nötig:

  1. Navigieren Sie in Azure zu ihrem Speicherkonto (biXX)
  2. In der linken Navigation klicken Sie unter dem Punkt Datenspeicher auf die Schaltfläche Container
  3. Wählen Sie biXX aus der Liste aus
  4. Klicken Sie auf die Schaltfläche Hochladen im oberen Bereich
  5. Wählen Sie die Willibald.bacpac Datei aus

Import des Core-DWH (2/2)

Nach dem nun alles benötigte vorhanden ist, können wir das
PowerShell-Skript ausführen um die Datenbank-Datei zu importieren

./main.ps1 -groupnumber X -sqlpassword "ryDZo5*~71[Q-"

Ab diesem Punkt wird im Hintergrund ein Prozess auf dem SQL-Server ausgeführt.

Der gesamte Prozess des Imports kann bis zu 15 Minuten dauern.

Klonen des Github-Repositorys (2/4)

Nun klonen wir das Github-Repository.

Wir empfehlen Ihnen die Übungen mithilfe der Entwicklungsumgebung Visual Studio Code umzusetzen.

Direkt auf der Willkommensseite finden Sie den Link zum Klonen eines Git-Repositorys.

Klonen des Github-Repositorys (3/4)

Nachdem Sie den Link auf der Willkommensseite angeklickt haben, öffnet sich eine Eingabeaufforderung, in welche Sie die vorher kopierte Clone-URL von Github einfügen. Und mit der Eingabetaste bestätigen.

Sie werden nun gebeten einen Speicherort auszuwählen, in den das Repository geklont wird. Wir empfehlen hierfür einen neuen Unterordner "dev" direkt in Ihrem Benutzerverzeichnis zu erstellen.

Klonen des Github-Repositorys (4/4)

Git fordert Sie auf sich gegenüber Github zu authentifizieren.

Klicken Sie auf "Sign in with your browser". Geben Sie Ihre Github-Zugangsdaten ein und erlauben Sie ggf. den Zugriff auf Ihr Github-Konto.

Sobald Sie dazu aufgefordert werden, schließen Sie das Browserfenster. Betätigen Sie die Schaltfläche "Open" in Visual Studio Code.

Der Editor öffnet nun ihr (noch leeres) lokales Repository und fragt ob Sie den Inhalten in diesem Verzeichnis vertrauen. Bestätigen Sie das.
