GitHub

Versionskontrolle einrichten

GitHub-Account anlegen

Wir nutzen Git als Quellcodeverwaltungssystem. Mindestens ein Gruppenmitglied benötigt einen GitHub-Account.

Sie können einen vorhandenen privaten Account nutzen oder einen neuen mit Ihrer HSH-Mailadresse anlegen:

→ Zur GitHub-Registrierung

Zugriff auf Gruppen-Repository beantragen

Öffnet ein GitHub-Issue nach Vorlage, um Zugriff auf das Repository eurer Gruppe zu erhalten:

→ Formular "Gruppen-Beitritt" öffnen

Tragt eure HSH-E-Mail-Adresse und eure Gruppennummer ein und sendet das Issue ab. Euer GitHub-Benutzername wird automatisch anhand eures eingeloggten Accounts erkannt.

Automatische Freischaltung

Eine GitHub Action prüft eure Angaben automatisch und:

  • fügt euch dem GitHub-Team eurer Gruppe hinzu (max. 3 Mitglieder)
  • kommentiert das Issue mit einem Link zu eurem Repository
  • schließt das Issue automatisch

Ihr erhaltet daraufhin eine Einladung zur Organisation hsh-bis242 und Zugriff auf euer Gruppen-Repository, z. B.:

https://github.com/hsh-bis242/bis-242-ws26-gruppe02
Tipp: Falls das Issue offen bleibt oder ein Fehler gemeldet wird, prüft eure Angaben oder wendet euch an den Dozenten.

Databricks Workspace

Cloud-Datenbank einrichten

Zugriff auf Databricks

Die Anmeldung erfolgt über Ihre Hochschul-Mail-Adresse.

→ Zum Databricks Workspace

Access Token generieren

  1. Oben rechts auf das User Profil klicken
  2. Settings → Developer → Access Token → Manage → Generate new Token
  3. Lifetime auf 180 Tage setzen und Token kopieren
⚠️ Speichern Sie den Token jetzt (z. B. in einer Textdatei). Er wird in den folgenden Schritten benötigt und kann danach nicht mehr angezeigt werden.

Variante A: GitHub Codespaces

Cloud-IDE im Browser

Codespace starten

⚠️ Voraussetzung: GitHub Codespaces mit ausreichend Stunden erfordern erfolgreich beantragte GitHub Education Benefits.
  1. Das Gruppen-Repository (bis-242-ws26-gruppeXX) auf GitHub öffnen
  2. Code → Codespaces → Create codespace on main
  3. GitHub startet eine VS-Code-Umgebung im Browser (Python vorinstalliert)
⚠️ Wichtig: Der Codespace muss im Gruppen-Repository erstellt werden, nicht im Template-Repository und nicht in einem fremden Repository.

Token als Codespace Secret hinterlegen

⚠️ Den Databricks Access Token immer als Codespace Secret hinterlegen. Ein per export gesetzter Token geht bei jedem Neustart des Codespace verloren.
  1. GitHub → Settings → Codespaces → Secrets → New secret
  2. Name: DATABRICKS_TOKEN, Value: Ihr Token
  3. Repository access: das Gruppen-Repository über die Suche (Name bis-242-ws26-gruppeXX eintippen) auswählen – es wird in der Liste nicht immer direkt angezeigt
  4. Codespace neu starten bzw. neu erstellen, damit das Secret verfügbar ist

Dokumentation Codespaces Secrets

Abhängigkeiten & venv

Im Codespace-Terminal ausführen:


python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
⚠️ GANZ WICHTIG: Die virtuelle Umgebung (.venv) muss in jedem neuen Terminal aktiviert sein ((.venv) vor dem Prompt). Sonst funktionieren die dbt-Befehle nicht – auch in allen weiteren Übungen.

Repository klonen (2/2)

  1. In VS Code: Clone Git Repository auf der Willkommensseite
  2. Clone-URL einfügen und bestätigen
  3. Speicherort wählen (z. B. ~/dev/)
  4. Bei Authentifizierung: "Sign in with your browser"

Python venv erstellen

  1. Python Extension in VS Code installieren
  2. View → Command Palette → "Python: Create Environment…"
  3. Venv als Environment Type wählen
  4. Dependencies aus requirements.txt installieren

Databricks Token setzen

Öffnen Sie ein Terminal in VS Code (View → Terminal):

🪟 Windows (PowerShell)


[Environment]::SetEnvironmentVariable(
  "DATABRICKS_TOKEN",
  "---> TOKEN <---", "User")

🍎 macOS / Linux


echo 'export DATABRICKS_TOKEN="---> TOKEN <---"' \
  >> ~/.zshrc
source ~/.zshrc

Anschließend VS Code neu starten.

Virtuelle Umgebung aktivieren

VS Code aktiviert die venv normalerweise automatisch. Falls nicht:

🪟 Windows (PowerShell)

.\.venv\Scripts\Activate.ps1

🍎 macOS / Linux

source .venv/bin/activate
