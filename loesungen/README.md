# Referenzlösungen für Übungen U03–U05

> **Nur für Dozenten.** Diese Lösungen werden nicht an Studierende verteilt.
> Sie dienen zur Bewertung der studentischen Abgaben und als Referenz für die Übungsbetreuung.

## Inhalt

| Datei | Übung | Beschreibung |
|-------|-------|-------------|
| `U03_Loesung.md` | U03 – dbt Einarbeitung | SQL-Modell + YAML-Dokumentation |
| `U04_Loesung.md` | U04 – Tests und Macros | SQL-Modell + YAML-Tests + Macro |
| `U05_Loesung.md` | U05 – Star Schema | dim_kunde + fact_bestellposition |

## Hinweise zur Bewertung

Jede Übung endet mit einer **"Ergebnis der Übung"**-Folie, die die prüfbaren Artefakte auflistet.
Die Dozenten können folgende Punkte kontrollieren:

- **Pull Request** im Gruppen-Repository (Branch `uebung` → `main`)
- **Dateien** im Pull Request: `.sql`, `.yml`, Macro-Dateien
- **Tabellen** im Databricks-Schema der jeweiligen Gruppe
- **Testergebnisse** (Screenshot in U04)

Die studentischen Lösungen müssen nicht exakt mit den Referenzlösungen übereinstimmen – es gibt mehrere korrekte Varianten.
