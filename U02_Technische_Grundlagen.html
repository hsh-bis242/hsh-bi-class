technische Grundlagen

Installation Editor

Auf dem Rechner des Teams sollte ein Code-Editor installiert sein.

Empfehlung: Herunterladen und installieren von Visual Studio Code

Installation git

Direkt über Visual Studio Code

Alternative: Download und manuelle Installation über git-scm hierbei die Standard-Einstellungen bei Installation übernehmen

Klonen des Repositories auf den lokalen Rechner

Aus dem DevOps Repository, welches in der vorherigen Übung angelegt wurde die http-clone-URL kopieren dev.azure.com

Einen Ordner auf dem Rechner wählen oder erstellen in dem das Repo geklont werden sollte, diesen Ordner in einem Terminal/Command-line Fenster öffnen und folgendes Statement ausführen und die gekopierte URL einsetzen: 

					git clone URL-HIER-EINSETZEN

Eine erneute Anmeldung mit dem Azure Microsoft-User ist erforderlich

Installation python

Python (python.org) installieren, wenn es nicht bereits auf dem Rechner installiert ist

checkmark setzen bei "Add python.exe to PATH"

Installation python

Im python installer "customize installation" auswählen und checkmark setzen bei pip, falls nicht bereits gesetzt

Installation python

Falls Python bereits installiert ist aber kein pip kann alternativ in der Command-line dieser Befehl pip installieren 

							py -m ensurepip --upgrade

Installation dbt

Auf der Command-line dbt mittels pip installieren 

					pip install dbt-sqlserver
Hinweis: Ein Neustart kann hier erforderlich sein damit pip genutzt werden kann bei Windows, die ENVIRONMENT PATH Variablen werden erst nach einen Neustart gesetzt

dbt Projekt initialisieren

Einen Terminal/Command-line Fenster öffnen im Ordner in dem das Repository in den ersten Schritten der Übung geklont wurde 

					dbt init

Bei der Installation als Projektnamen HSH_BI eingeben und die 1 für SQl-Server auswählen und bestätigen

dbt Projekt initialisieren

Ein dbt-Projekt hat auch immer ein profiles.yml file welches die Connection Infos zur Datennbak enthält, mittels dieses Befehls kann der Speicherort der Datei ermittelt werden 

					dbt debug --config-dir

Den "start" Befehl der aus diesem command erzeugt wird auch auf der command-line ausführen, dann sollte sich der Speicherpfad öffnen unter den das profiles.yml file gespeichert werden sollte
