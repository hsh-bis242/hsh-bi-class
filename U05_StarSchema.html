Virtuelle Umgebung aktivieren

Wichtig: Vor dem Ausführen von dbt-Befehlen muss die virtuelle Umgebung aktiviert sein.

VS Code aktiviert die venv normalerweise automatisch. Falls nicht:

Windows (PowerShell):


.\.venv\Scripts\Activate.ps1

macOS / Linux:


source .venv/bin/activate

Aufgabenstellung - DWH Modell

Analysieren des DWH Modells und der Data Vault Objekte

  • Analysieren Sie die Hubs, Links und Satelliten aus dem bestehenden DWH Modell
  • Nutzen Sie "dbt complile -s ..." um die DV Objekte und Macros besser zu verstehen
  • Erstellen Sie ein macro, das eine View erzeugt, die den gültigen Stand für einen Satelliten filtert.
  • Erstellen Sie mithilfe des Macros eine "Current Views" zu allen Satelliten
  • Änderungen am dbt-Projekt ins Github-Repository auf den branch "uebung" pushen

Aufgabenstellung - Stern Schema Data Mart

Implementieren Sie das von Ihnen modellierte Sternschema in dbt.

  • Legen Sie Ihr Datenmodell im Schema "ol_dm" an.
  • Nutzen Sie die Hubs, Links und Satelliten aus dem bestehenden DWH Modell
  • Nutzen Sie die Current Views aus dem vorherigen Teil der Übung
  • Erstellen Sie dbt-Modelle (.sql files) um Ihr Sternschema in Databricks zu erzeugen und zu beladen.
  • Änderungen am dbt-Projekt ins Github-Repository auf den branch "uebung" pushen

Ergebnis der Übung

  • macro für Satellit current View erstellt
  • Current Views für Satelliten erstellt
  • Textdatei mit möglichen Fakten- und Dimensionstabellen erstellt
  • min. 1 Faktentabelle und 3 Dimensionstabellen im schema "ol_dm" in dbt erstellt
  • dbt Modelle und Macros in das Git Repository gepusht (branch = uebung)
