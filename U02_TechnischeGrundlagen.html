Übung Business Intelligence

Technische Grundlagen

dbt Projekt initialisieren

Einen Terminal/Command-line Fenster öffnen im Ordner in dem das Repository in den ersten Schritten der Übung geklont wurde 

					dbt init

Bei der Installation als Projektnamen HSH_BI eingeben und die 1 für SQL-Server auswählen und bestätigen

dbt Projekt initialisieren

Ein dbt-Projekt hat auch immer ein profiles.yml file, welches die Connection Infos zur Datenbank enthält, mittels dieses Befehls kann der Speicherort der Datei ermittelt werden 

					dbt debug --config-dir

Den "start" Befehl der aus diesem command erzeugt wird auf der command-line ausführen, dann sollte sich der Speicherpfad der profiles.yml öffnen, im Normalfall existiert diese noch nicht

profiles.yml erstellen

Im Ordner aus dem vorherigen Schritt ein "profiles.yml" file erstellen mit folgenden Inhalt

In server, database und user xx mit der Gruppennummer ersetzen, ebenfalls das Passwort aus der ersten Übung für den Azure SQL Server einsetzen 

				  HSH_BI:
	target: dev
	outputs:
		dev:
			type: sqlserver
			driver: 'ODBC Driver 18 for SQL Server' # (The ODBC Driver installed on your system)
			server: bi230xx-exercise-sql.database.windows.net
			port: 1433
			database: bi230xx-db
			schema: SalesLT
			user: bi230xx
			password: xxxxxx

Konfiguration Testen

Im Ordner HSH_BI dieses command-line statement ausführen 

					dbt debug

Wenn die Ausführung erfolgreich war, werden diese Ergebnisse angezeigt:

Sollte der "Connection test" fehlschlagen könnte der ODBC Treiber auf dem Rechner noch fehlen. Diesen bitte herunterladen auf microsoft.com und installieren

dbt run test

Im Ordner HSH_BI dieses command-line statement ausführen 

					dbt run

Dieser Befehl erstellt die test models aus dem Folder models/example/ des dbt-Projekts in der Datenbank, bitte dies einmal mit dem gewählten DBMS-Tool prüfen, ob die Tabelle my_first_dbt_model und die view my_second_dbt_model in der Datenbank erstellt wurden

Repo aktualisieren

DBT ist nun vollständig eingerichtet und es kann vom Rechner Datenbank-Objekte erzeugt und getestet werden in der Azure Cloud.

Abschließend sollte das dbt-Projekt noch in das DevOps Repo synchronisiert werden. Im Repository-Ordner (eine Ebene höher als der HSH_BI Ordner), den gesamten HSH_BI Ordner auf den git stash packen mit 
					git add HSH_BI
Die Änderungen in ein commit packen 
					git commit -m "initial dbt project"
Der Aktuelle Stand wird in das remote Repository gepusht 
					git push
