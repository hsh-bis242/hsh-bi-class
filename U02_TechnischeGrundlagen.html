Git Workflow

Änderungen sichern

Commit & Push

Sichern Sie Ihre Änderungen regelmäßig mit Git:

  1. In VS Code die Source Control-Ansicht öffnen (Sidebar-Icon)
  2. Geänderte Dateien mit + stagen
  3. Commit-Nachricht eingeben und ✓ Commit klicken
  4. Mit Push die Änderungen auf GitHub hochladen
